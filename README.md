# 🎓 Student Management System (React)

A smart Student Management Portal built using React.js for managing student records, analytics, and department-wise data with a clean dashboard UI.

---

## 🚀 Features

- 📊 Dashboard with student statistics
- ➕ Add new students
- ✏️ Edit student details
- ❌ Delete students
- 🔍 Search by name or ID
- 📚 Department-wise tracking
- 💰 Fee status tracking
- 📈 Charts using Recharts
- 🧭 Sidebar navigation (Dashboard, Students, Departments, Settings, Help)

---

## 🛠️ Tech Stack

- React.js
- JavaScript
- CSS
- Recharts
- React Icons

---

## 📂 Installation & Setup

npm install  
npm start
